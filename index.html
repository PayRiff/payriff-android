Payriff Android SDK

This is Payriff's Maven repository for com.payriff:payriff-android, built and published from github.com/PayRiff/payriff-android by its release workflow.

// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://payriff.github.io/payriff-android/maven") {
            content { includeGroup("com.payriff") }
        }
    }
}

See the README for the current version.
